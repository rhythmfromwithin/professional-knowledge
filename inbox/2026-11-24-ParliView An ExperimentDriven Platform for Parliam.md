# ParliView: An Experiment-Driven Platform for Parliamentary Transparency
> 原文: [https://arxiv.org/abs/2611.27991](https://arxiv.org/abs/2611.27991)

arXiv:2611.27991v1 Announce Type: new
Abstract: ParliView is a modular, agentic retrieval-augmented generation platform for querying European Parliament records. It provides a natural language interface for citizens to explore parliamentary debates and activities, and a controlled experimentation environment in which different users can be exposed to systematically varied system behaviours. This enables rigorous study of how design choices, such as verbosity, interactivity, and source presentation, affect user trust, comprehension, and reliance. We describe the system architecture and demonstrate its two core interfaces.
