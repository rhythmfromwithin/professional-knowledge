# Designing an Integrated Learning Ecosystem for Introductory Python Programming: Scaffolded Problem Solving, Tablet-Inspired Navigation, and AI-Enhanced Instruction
> 原文: [https://arxiv.org/abs/2611.33471](https://arxiv.org/abs/2611.33471)

arXiv:2611.33471v1 Announce Type: new
Abstract: Introductory programming requires students to represent problems, develop and test programs, debug errors, and apply computational ideas in new contexts. In this paper, we present an artifact-centered design analysis of an integrated learning ecosystem developed for a 16-lab introductory Python course. The analyzed corpus comprises 18 instructional artifacts: the course syllabus, a tablet-inspired homepage, and Labs 1-16. We examined course navigation, problem representation, scaffolding, independent transfer, application development, debugging, AI integration, and assessment. All 15 scaffolded labs shared seven elements: input-processing-output (IPO) reasoning, instructor-guided programming, an independent task, a Google Colab/Gradio extension, debugging support, a task checklist, and submission requirements. Lab 16 departed from this structure as an integrative Pygame-based Hallmark Assignment. The analysis identifies four connected design features: a navigation layer that coordinates multiple tools; two forms of transfer, from guided to independent problems and from console programs to interactive interfaces; distinct roles for instructor-side AI-enhanced communication and student-side AI assistance; and a transition from repeated scaffolds to integrative problem solving. The case also identifies unresolved tensions involving tool fragmentation, accessibility, interface distraction, student authorship, and overreliance on AI. Because student learning outcomes were not examined, we make no claims about instructional effectiveness. Instead, the paper offers a transparent design precedent and identifies priorities for future empirical evaluation.
