# Development of an Effective Federated Learning-Based Defense System Against Phishing Attacks on Mobile Platforms
> 原文: [https://arxiv.org/abs/2611.28245](https://arxiv.org/abs/2611.28245)

arXiv:2611.28245v1 Announce Type: new
Abstract: Phishing remains one of the most pervasive and damaging cyber threats, exploiting both technical flaws and human behavior to compromise sensitive data. We present a privacy-preserving, real-time defense that analyzes full webpage source code on mobile platforms. Our system combines a lightweight Convolutional Neural Network (CNN) for end-to-end feature extraction with a Federated Learning (FL) framework that updates models collaboratively on user devices without transferring raw data-supporting regulatory compliance and personalization. Evaluated on a large and diverse dataset, the model attains 86.02\% accuracy, 90.35\% precision, 80.64\% recall, and 92.78\% ROC-AUC. While some centralized, classical approaches may report higher accuracy, our design emphasizes a practical balance among accuracy, user privacy, and real-time performance on resource-constrained devices. We further demonstrate an end-to-end integration within the open-source Lightning Android browser, achieving real-time detection with low computational overhead. This work shows that privacy-first, AI-driven phishing detection is both feasible and scalable across mobile and IoT settings, delivering robust protection while keeping user data on-device.
