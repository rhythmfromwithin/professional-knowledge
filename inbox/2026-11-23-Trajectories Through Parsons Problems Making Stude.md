# Trajectories Through Parsons Problems: Making Student Difficulty Patterns Visible to Instructors
> 原文: [https://arxiv.org/abs/2611.26799](https://arxiv.org/abs/2611.26799)

arXiv:2611.26799v1 Announce Type: new
Abstract: Existing Parsons problem tools primarily focus on correctness, indicating whether a student solved a problem, but providing limited visibility into the underlying problem-solving process. Without that visibility, instructors cannot see which blocks caused repeated confusion or which distractors were consistently selected. We introduce Pulla, a Parsons problem tool that instruments programming assignments to capture fine-grained interaction data. We examine what these behavioral traces make visible to instructors, namely how long students take on a problem and how many moves they make, which recurring errors the distractors expose and how the class arrives at them, whether those errors follow a student from one problem to the next, and which students complete the whole assignment without a single error.
