# LLMs are making formal software verification feasible at a much larger scale
> 原文: [https://www.anthropic.com/research/formal-verification](https://www.anthropic.com/research/formal-verification)

Formal verification can prove that code is free of certain bugs, but historically it has only been feasible for small codebases. With AI models, however, this is beginning to change. Here, we used Claude to prove security properties in over one hundred real-world open-source libraries over the span of a few weeks.
