# Trajectools Demo: Towards No-Code Solutions for Movement Data Analytics
> 原文: [https://arxiv.org/abs/2610.06858](https://arxiv.org/abs/2610.06858)

arXiv:2610.06858v1 Announce Type: new
Abstract: This demo paper presents the conceptual foundations and the first steps towards implementation of a novel no-code solution for movement data analytics based on the open-source Python library MovingPandas and the open-source geographic information system QGIS. The resulting Trajectools plugin is available open-source at https://github.com/movingpandas/qgis-processing-trajectory.
