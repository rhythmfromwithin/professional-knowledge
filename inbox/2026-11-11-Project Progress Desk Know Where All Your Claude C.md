# Project Progress Desk: Know Where All Your Claude Code and Codex Projects Stand at a Glance
> 原文: [https://arxiv.org/abs/2611.13287](https://arxiv.org/abs/2611.13287)

arXiv:2611.13287v1 Announce Type: new
Abstract: Codex and Claude Code let developers work on many projects in parallel, but keeping track of them still means switching between chats, terminal sessions and providers. We present Project Progress Desk, a local desktop interface that brings overall progress, blockers and pending decisions into one view. Users can see which projects need attention, inspect what remains, and compare earlier approaches before choosing how to continue. Agent receipts link reported outcomes to each project's weighted acceptance checklist; the overview distinguishes receipt-supported progress from dated estimates. We describe daily use across 36 projects, including a choice between two implementations based on their recorded outcomes. At the demo, attendees will explore 30 simulated projects, trace completed work to overall progress, and watch a coding agent's new result update the overview.
