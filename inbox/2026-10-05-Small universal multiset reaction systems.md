# Small universal multiset reaction systems
> 原文: [https://arxiv.org/abs/2610.03021](https://arxiv.org/abs/2610.03021)

arXiv:2610.03021v1 Announce Type: new
Abstract: This paper presents a construction of a small universal machine within the framework of Multi-set Reaction Systems. We encode the machine state using elements that represent registers and instruction labels, and we enforce sequential execution by ensuring that reaction chains for a given instruction can only activate after the corresponding label element appears. We implement a universal register machine with 8 registers and 23 instructions, showing that the priority-based model requires 87 distinct elements. The results demonstrate that multiset reaction systems are capable of simulating universal computation.
