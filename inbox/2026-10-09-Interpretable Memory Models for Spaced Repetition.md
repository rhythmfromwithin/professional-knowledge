# Interpretable Memory Models for Spaced Repetition
> 原文: [https://arxiv.org/abs/2610.10548](https://arxiv.org/abs/2610.10548)

arXiv:2610.10548v1 Announce Type: new
Abstract: Spaced repetition software schedules reviews with a memory model fit to review logs. Accuracy on a test set is not sufficient evidence of quality since available data are produced by existing schedulers, and new solutions must extrapolate beyond them. A model also needs a simple mechanistic interpretation. We present SBD, a model that is more interpretable and 80% smaller than the current state of the art at nearly the same accuracy.
