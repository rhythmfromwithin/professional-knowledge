# Simulating Episodic Like Memory in Octopus: Breaking the Rules
> 原文: [https://arxiv.org/abs/2611.28409](https://arxiv.org/abs/2611.28409)

arXiv:2611.28409v1 Announce Type: new
Abstract: Episodic memory, which involves the recollection of past events, has been observed in several species including the invertebrate cuttlefish. In a subsequent experiment, episodic memory was not observed in the closely related octopus. Rather the octopus used simpler, cognitive rule-based strategies to gain access to food. Using a prior model of cuttlefish episodic-like memory, we replicated the octopus experiment. Under less challenging conditions, episodic memory and the simpler cognitive strategies all had positive gains. However, under more challenging conditions, which introduced the threat of predation, only the episodic memory model had positive gains. These results suggest that if challenged ecologically, it would be advantageous for octopus to use episodic-like memory. We discuss possible reasons for the behavioral discrepancies in these closely related cephalopods.
