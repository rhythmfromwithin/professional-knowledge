# Spiking neuromodulation: a linear control perspective
> 原文: [https://arxiv.org/abs/2611.08571](https://arxiv.org/abs/2611.08571)

arXiv:2611.08571v1 Announce Type: new
Abstract: Neuronal excitability is a nonlinear phenomenon, and the complexity of spiking experimental traces sometimes looks defeating. The present paper takes the view point that excitability is a neuromodulated property, and aims to demonstrate that the neuromodulation of spiking is amenable to the classical linear analysis tools of control theory. We illustrate the value of linear feedback analysis as an alternative to bifurcation analysis in the simple yet classical example of spiking modulation by the A-type potassium current.
